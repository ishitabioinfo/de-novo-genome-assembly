# de-novo-genome-assembly
# De Novo Genome Assembly and Functional Annotation using SPAdes, QUAST and Prokka

## Project Overview
This project demonstrates the de novo assembly and functional annotation of a bacterial genome using open-source bioinformatics tools.

## Objective
- Perform quality assessment of sequencing reads.
- Assemble the genome using SPAdes.
- Evaluate assembly quality using QUAST.
- Annotate the assembled genome using Prokka.

## Dataset
- Organism: Escherichia coli
- Source: NCBI Sequence Read Archive (SRA)

## Tools Used
- FastQC
- Trimmomatic
- SPAdes
- QUAST
- Prokka

## Workflow
1. Download sequencing reads from NCBI SRA.
2. Perform quality control using FastQC.
3. Trim low-quality reads using Trimmomatic.
4. Assemble the genome using SPAdes.
5. Evaluate assembly quality using QUAST.
6. Annotate the assembled genome using Prokka.

## Results
The genome was successfully assembled and annotated, identifying coding sequences and other genomic features.

## Future Scope
This workflow can be extended to comparative genomics and bacterial genome analysis.
